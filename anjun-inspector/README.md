# Anjun Auto Inspector
Android app for local, passive accessibility layout observations. It does not tap buttons, submit deliveries, generate signatures, capture customer text, or send data to external services. Enable the service manually in Android Accessibility settings, browse the Anjun app yourself, then share the anonymized report.

Build: GitHub Actions -> Build Anjun Inspector APK -> artifact AnjunAutoInspector-debug-apk. Debug APK is for testing only. Do not enable Accessibility for untrusted apps.
